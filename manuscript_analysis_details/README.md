## Reproducing Results from psaps in the Associated Manuscript

To reproduce results from psaps from our manuscript, please simply run psaps with the input files in the `test_case` subdirectory within the main folder of the psaps git repository. Expected results matching what was used for the manuscript are provided there.

Relevant information of conda environments for psaps and OrthoFinder (used to create one of the inputs) used for the manuscript can be found within this subdirectory: `psaps_conda_env.yaml` and `conda_env_with_orthofinder.yaml`.

Additional files pertaining to psaps analysis related files and scripts can be found on the official git repository for the manuscript at: [https://github.com/Kalan-Lab/Ancestral_BGC_Exansions_Study/tree/main/09_Fungal_Comparative_Genomics_and_Phylogenomics/Pangenome_Expansion_Analysis](https://github.com/Kalan-Lab/Ancestral_BGC_Exansions_Study/tree/main/09_Fungal_Comparative_Genomics_and_Phylogenomics/Pangenome_Expansion_Analysis). Details pertaining to psaps algorithm design and rationale for developing can be found on the main README and in the Supplemental Methods of the manuscript.
